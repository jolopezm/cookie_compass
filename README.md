# Cookie Compass

Sistema de gestión de pedidos para panadería/pastelería construido con Web Components nativos, JavaScript vanilla y Supabase.

**Características principales:**
- Gestión de clientes, productos y órdenes (CRUD completo)
- Tabla de datos con selección múltiple, ordenamiento y filtros avanzados
- Creación de órdenes con selección de cliente y productos, cálculo automático del total
- Persistencia en Supabase (PostgreSQL) con caché offline en localStorage
- Interfaz responsive con Pico CSS

## Inicio rápido

```bash
npm install
npm run dev
```

## Comandos disponibles

| Comando | Descripción |
|---|---|
| `npm run dev` | Inicia servidor de desarrollo con Vite |
| `npm run build` | Compila para producción |
| `npm run preview` | Previsualiza la build de producción |
